Journal des opérations. Chaque commande, requête, changement de statut, paiement, remise de documents et modification du catalogue y est enregistré automatiquement, avec sa date et son heure. Chaque entrée porte une empreinte SHA-256 qui la relie à la précédente : une modification ou une suppression après coup est détectée par « Vérifier l'intégrité ».
Ce journal contient des données personnelles. Ne le transmettez qu'aux autorités habilitées, sur demande officielle (réquisition, enquête), ou pour défendre vos droits.

Publier vos projets

Le site est statique : la liste des projets se trouve dans le fichier data/projets.json. Pour mettre en ligne vos modifications :

  1. Cliquez sur Télécharger projets.json.
  2. Remplacez le fichier data/projets.json de votre dépôt GitHub par celui-ci (bouton « Add file → Upload files »).
  3. Si vous utilisez des modèles .glb, déposez-les dans le dossier modeles/.
  4. Le site se met à jour automatiquement (GitHub Pages / Netlify) en 1 à 2 minutes.
🔒 Détails réservés. Le fichier public projets.json ne contient jamais les détails réservés aux acheteurs : description architecturale, cotes, tableau des surfaces, notes techniques. Ces détails restent dans ce navigateur. Sauvegardez-les régulièrement avec « Sauvegarder les détails réservés » et gardez ce fichier en lieu sûr (clé USB, Google Drive privé). Ne déposez jamais ce fichier sur GitHub : le dépôt est public.
