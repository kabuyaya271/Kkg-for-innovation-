Publier vos projets

Le site est statique : la liste des projets se trouve dans le fichier data/projets.json. Pour mettre en ligne vos modifications :

  1. Cliquez sur Télécharger projets.json.
  2. Remplacez le fichier data/projets.json de votre dépôt GitHub par celui-ci (bouton « Add file → Upload files »).
  3. Si vous utilisez des modèles .glb, déposez-les dans le dossier modeles/.
  4. Le site se met à jour automatiquement (GitHub Pages / Netlify) en 1 à 2 minutes.

Astuce : les images ajoutées ici sont intégrées dans le JSON. Pour un site plus rapide, placez plutôt vos images dans le dossier images/ et indiquez leur chemin.
