# Monter vos vidéos avec l'IA, gratuitement (OpenCode)

Méthode de la vidéo « Comment monter tes vidéos avec l'IA 100 % gratuitement », adaptée à KKG for Innovation.

## Étape 1 — Installer OpenCode (gratuit)
Téléchargez l'application sur **opencode.ai** (Windows, macOS ou Linux), ou en ligne de commande :
`npm install -g opencode-ai`

## Étape 2 — Choisir un modèle gratuit (sans compte ni abonnement)
Dans la barre de saisie, choisissez l'un de ces modèles marqués **Free** :
- `GLM-5.3-Flash` (recommandé), `DeepSeek V4.1 Flash`, `Big Pickle`.

## Étape 3 — Installer les outils de montage
Ouvrez ce dossier `montage/` dans OpenCode et écrivez :
> Installe-moi Remotion et HyperFrames.

## Étape 4 — Préparer le dossier
- Mettez la vidéo à monter dans ce dossier (ex. `video.mp4`).
- Mettez des vidéos d'inspiration dans `inspiration/` (téléchargées avec cobalt, noTube ou SSSInstagram, uniquement pour analyse, pas pour republier).

## Étape 5 — Expliquer votre contenu
Le fichier `METHODE-MONTAGE.md` contient déjà : type de contenu, thématique, audience, structure, styles.
Si vous voulez le refaire avec l'IA :
> Analyse les vidéos du dossier inspiration (hook, zooms, sous-titres, B-roll, motion design) et mets à jour METHODE-MONTAGE.md avec la stratégie, la méthode et les styles.

## Étape 6 — Monter
> Monte video.mp4 en suivant METHODE-MONTAGE.md avec Remotion. Fais une V1.

Regardez la V1, demandez les corrections, puis V2, V3…

## Depuis GitHub (sans ordinateur)
Sur le dépôt, ouvrez une issue et écrivez en commentaire `/oc …` : OpenCode travaille gratuitement (modèle `glm-5.3-flash-free`) et propose une pull request.
